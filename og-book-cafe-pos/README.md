# OG Book Cafe POS (Supabase + Vercel)
A ready-made, offline-capable point-of-sale for OG Book Cafe, preloaded with the cafe's Drinks and Little Bites menu, and a loud alert sound whenever an order is sent to the kitchen.

Full instructions: **SETUP-GUIDE.md**.

Quick path: run `supabase/schema.sql`, add the owner user, edit `config.js`, then `vercel --prod`.
